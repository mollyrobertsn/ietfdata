\begin{enumerate}
    \item \textbf{Do changes in RFC topics, publication status, or references
    to earlier RFCs help explain changes in publication numbers, document
    length, and team size?}
    \begin{itemize}
        \item Compare yearly results across RFC status, keywords, and working
        groups to see whether the mix of RFCs has changed over time.
        \item Use the RFC Editor's abbreviation list to look for changes in
        terms used in RFC texts. Check a sample of matches to avoid counting
        ordinary words.
        \item Extract references from RFC reference lists and compare citation
        patterns with length, status, and author-team size. Keep these
        separate from the index's ``updates'' and ``obsoletes'' links.
    \end{itemize}

    \item \textbf{Do changes in recorded author countries reflect changes in
    affiliations, gaps in the available data, or both?}
    \begin{itemize}
        \item Check which project sources contain country information and
        whether the records can be linked reliably to RFC authors.
        \item Compare the countries recorded over time, while also reporting
        how many author records have missing or uncertain country information.
        \item Treat a recorded country as an affiliation, not as evidence of
        nationality. If the data is too incomplete, describe the gap rather
        than presenting the results as representative.
    \end{itemize}

    \item \textbf{Do changes in the organisations linked to RFC authors line
    up with changes in RFC output and team size?}
    \begin{itemize}
        \item Check whether authors can be linked to organisations and whether
        those affiliations were recorded near the RFC's publication date.
        \item Compare the organisations represented over time with the number
        of RFCs and listed authors. Note when a few organisations account for
        a large share of the records.
        \item Keep unmatched authors visible, and do not treat current
        affiliations as historical ones.
    \end{itemize}
\end{enumerate}

Check extracted references and author links against source records. Report
missing or uncertain data, and treat any patterns as associations rather than
proof of what caused the changes.
