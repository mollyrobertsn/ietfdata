\begin{enumerate}
    \item \textbf{To what extent are long-term changes in RFC publication
    volume, document length, and listed author-team size associated with
    changes in topic and publication-status mix, and with references to
    earlier RFCs?}
    \begin{itemize}
        \item Compare annual publication volume, document length, and team
        size across RFC topics and publication statuses.
        \item Use the RFC Editor's abbreviation list to examine changes in
        abbreviations used in RFC texts. Check a sample of matches to avoid
        counting ordinary words.
        \item Extract references from RFC reference lists and compare them
        with document length, status, and team size. Keep these references
        separate from the index's ``updates'' and ``obsoletes'' links.
    \end{itemize}

    \item \textbf{What accounts for changes in the recorded geographic
    representation of RFC authors: changes in identifiable author
    affiliations, differences in metadata coverage, or both?}
    \begin{itemize}
        \item Check which project sources contain country information and
        whether the records can be linked reliably to RFC authors.
        \item Compare recorded countries over time and report how many author
        records have missing or uncertain country information.
        \item Treat a recorded country as an affiliation, not as evidence of
        nationality. If the data is too incomplete, describe the gap rather
        than presenting the results as representative.
    \end{itemize}

    \item \textbf{Has RFC work become more concentrated in particular topics
    or working groups over time?}
    \begin{itemize}
        \item Compare the distribution of RFCs across indexed keywords and
        working groups in different periods.
        \item Measure whether a smaller set of topics or working groups
        accounts for a larger share of RFCs over time.
        \item Report changes in keyword coverage and interpret the results
        as patterns in the indexed records, not as a complete account of RFC
        topics or IETF participation.
    \end{itemize}
\end{enumerate}

Check extracted references and author links against source records. Report
missing or uncertain data, and treat any patterns as associations rather than
proof of what caused the changes.
